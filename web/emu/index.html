FM‑23 Guide (buttons · pages · gestures)
  • HOME pads · SEQ pattern/chain · ARP arp · GEN (SCL) · FX · GLO
  • MOD page (ENV/LFO): ATTACK / RELEASE / DECAY / PITCH and ON / RATE / DEPTH / SHAPE — per selected voice
  • EDIT cycles BASS → LEAD → DRUMS → LAYER: ENGINE (voice), filters/drive/level, PORTA, ARCH
  • Change the sound: EDIT → ENGINE — BASS 0 classic / 1 B01 / 2 B02 / 3 B03 / 4 B04 acid (default) · LEAD 0 classic / 1 L01 / 2 L02 / 3 L05 / 4 L07 / 5 L03 / 6 L04 / 7 L06 scream (default)
  • LAYER (EDIT): PERF 0 SINGLE / 1 DUAL / 2 SPLIT · VOICE 0 RETRIG / 1 LEGATO / 2 UNISON · ANALOG drift · SPLIT NOTE
  • SELECT moves the cursor · ALGORITHM edits it · KNOB 1–4 edit the rows
  • PLAY start/stop · REC arm · SAVE saves the current page's data
  • SEQ: keys toggle steps; REC+key cycles step velocity (90/110/127)
  • SEQ → PART=1: chain editor — keys 0–7 choose the bank cell for the chain step
  • GEN: twisting ROOT/SCALE/STYLE regenerates; MODE → SONG builds the 8-cell chain
  • TD‑3 lanes: SLIDE (glide, cross-pattern) and GATE (note length) travel with patterns
  • OCT− + OCT+ held 5 s = recovery (UBOOT) — never used for anything else
  • Keys: 0–7 drum pads · 8–17 bass · 18–26 lead
